# Régimen de Transición

Este directorio contiene imágenes de llamas en régimen de transición.

## Características del Régimen de Transición
- Flujo intermedio entre laminar y turbulento
- Presencia de vórtices intermitentes
- Número de Reynolds intermedio (2300 < Re < 4000)
- Llama con fluctuaciones moderadas

## Formato de Imágenes
- Formato recomendado: JPG, PNG, TIFF
- Resolución mínima recomendada: 640x480 píxeles
- Nomenclatura sugerida: `transicion_001.jpg`, `transicion_002.jpg`, etc.
