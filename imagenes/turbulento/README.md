# Régimen Turbulento

Este directorio contiene imágenes de llamas en régimen turbulento.

## Características del Régimen Turbulento
- Flujo caótico y desordenado
- Formación de remolinos y vórtices
- Alto número de Reynolds (Re > 4000)
- Llama con alta variabilidad e inestabilidad

## Formato de Imágenes
- Formato recomendado: JPG, PNG, TIFF
- Resolución mínima recomendada: 640x480 píxeles
- Nomenclatura sugerida: `turbulento_001.jpg`, `turbulento_002.jpg`, etc.
