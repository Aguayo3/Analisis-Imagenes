# Régimen Laminar

Este directorio contiene imágenes de llamas en régimen laminar.

## Características del Régimen Laminar
- Flujo suave y ordenado
- Capas de fluido se mueven en paralelo
- Bajo número de Reynolds (Re < 2300)
- Llama estable y bien definida

## Formato de Imágenes
- Formato recomendado: JPG, PNG, TIFF
- Resolución mínima recomendada: 640x480 píxeles
- Nomenclatura sugerida: `laminar_001.jpg`, `laminar_002.jpg`, etc.
